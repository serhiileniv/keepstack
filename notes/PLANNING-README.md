# AI Hub — planning

The workspace for a **pet project**: a public hub of the AI tooling I actually use, plus what
I've tried and what I dropped — every entry dated and checked against named model versions.

Not a startup. One person, spare weekends, ~$12/year.

```
PLAN.md        the whole plan, one page
DECISIONS.md   calls made, and why. Append-only
hub/           the actual project — this is what gets published
archive/       the startup version, abandoned 2026-08-30. Some of it is still good
```

## The project, in three lines

1. Publish the agent setup I really run — skills, `CLAUDE.md`, MCP configs, permissions.
2. Add what I've **tried and dropped**, which is the part nobody else publishes.
3. Date every entry. `Last checked: 12 Aug 2026 · opus-5` is more than any awesome-list gives you.

## Why it can work

Every `awesome-*` list on GitHub is a graveyard of untested links. Nothing on the internet tells
you whether a given AI tool or config **still works today**. That gap is not filled by
collecting more links; it's filled by re-checking and saying when you last did.

The content is a by-product of a normal working day, so there's no research burden — which is
the only reason a one-person, no-schedule project has a chance of surviving.
