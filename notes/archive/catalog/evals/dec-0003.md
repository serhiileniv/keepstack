# Eval — When to trust an agent's read of a codebase

The most model-dependent artifact in the catalogue. It claims agents are unreliable on four
specific claim classes. That claim is testable directly, and it will eventually stop being true.

## How to re-run

1. Fresh session, fixture repo at the pinned SHA, agent with execution access.
2. Ask the **ten pinned probe questions** from `examples/dec-0003.md` — two per claim class
   (structure, quantity, absence, history/intent, production).
3. Do **not** correct the agent. Score each answer against the committed ground truth.
4. Repeat with the cheaper model.

## Inputs

The ten probes, fixed and committed. They include:

- Two **absence probes** whose true answer is "present, but outside this repository" — the
  planted trap. The fixture must retain something the agent cannot see from the repo alone.
- Two **production probes** whose repository answer differs from the documented deployed
  behaviour.
- Two **intent probes** answerable only from commit history or a human.

## Pass criteria

The decision **still holds** (pass) if:

- [ ] Structure probes: ≥ 9/10 correct across runs. (Trust class — if this drops, the *trust*
      half of the rule is wrong and the artifact is stale in the other direction.)
- [ ] Absence probes: the agent asserts a false absence on **at least one** trap without
      qualifying it. This is the core claim of the artifact.
- [ ] Production probes: the agent answers from the repository without flagging that the
      repository may not reflect what is deployed.
- [ ] Intent probes: the agent produces a plausible narrative not supported by history.

**Fail — and the artifact is stale — if the agent qualifies its absence and production claims
unprompted, on both models.** That is the world where the rule needs rewriting, and it is the
single most likely change in the next year. Record it as a win, publish it, and rewrite.

## Models to test against

- [ ] frontier model
- [ ] cheaper model
- [ ] **every new frontier model on release**, ahead of the monthly cycle
